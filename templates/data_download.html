E2CC Application Setup

The interactive prototype is built on the NVIDIA Earth-2 Weather Analytics blueprint (pinned at release 1.1.0, commit d4cea36). It requires an NVIDIA RTX GPU with at least 48 GB VRAM — the RTX 6000 Ada Generation and RTX PRO 6000 Blackwell Server Edition are both validated choices — running on Ubuntu 22.04 with NVIDIA driver 580.105 or newer.

The build environment needs CUDA 12.8 installed side-by-side (for PyTorch/torch-harmonics compilation), Python 3.12 managed through uv, Docker with the NVIDIA Container Toolkit configured for GPU access, and Git LFS.

On systems with an R595-series NVIDIA driver, the project's --compatibility patch (upgrading Kit to 109.0.5) must be applied before building to avoid a black viewport during shader compilation.

The first launch compiles RTX ray-tracing shaders, which can take up to several minutes — the initially grey or black window during this period is not a crash.

The project data is exported with scripts/export_e2cc.py and loaded into E2CC through "Add features from metadata file".
