About Earth as a Graph

Project Overview

The Earth as a Graph project is part of the Thinking Earth project, and is focused on developing a data-driven representation of the Earth using a graph-based structure. The approach leverages the inherent interconnectedness of Earth systems through self-supervised graph learning methods. Our model aims to capture and predict the state of the Earth while highlighting complex interdependencies within the data.

The interactive prototype offers insights into the behavior of the Earth as a Graph model, which is currently under development. This model explores spatial interconnections within weather data and auxiliary learning objectivesusing ERA5 datasets provided by ECMWF.

By visualizing both the model's predictions as well as additional insights into the model's internal representations, the prototype provides a window into the model's learning dynamics. It reflects the current state of the model and helps illustrate how spatial relationships in climate data are captured and learned over time.

As this is part of an ongoing research project, we are not disclosing further technical details at this stage. The prototype will be expanded in the future, following the release of the final model, and will include comprehensive visualizations and a detailed description of the model architecture and setup.

Dashboard Features

The main dashboard provides an intuitive interface for selecting various parameters related to the choice of model. Users can select from different datetimes throughout the test year 2018, four variables (Temperature, Geopotential Height at 500hPa, WindSpeed surface and Total Column Water Vapour).

Visualization Components

The platform features a dual-panel prediction visualizer that displays model predictions alongside ground truth data for direct comparison. The system dynamically loads variable-specificvisualization images, allowing users to analyze how model performance varies with different datapoints and variable selections. Additionally, an attention-based spatial grouping panel provides insights into how the model focuses on different geographical regions during prediction, as well as a visualization of learned segmentation tasks to segment extreme weather events. Additionally, a spatial evaluation of the model's predictions is provided, showing the model's predictions compared to a comparable baseline model.

Interactive Analysis

Through the parameter selection interface, researchers can explore how environmental predictions change for different datetimes, variables and model training iterations. This enables comprehensive analysis of model behavior, prediction accuracy, and spatial-temporal patterns in Earth system dynamics.
