About Earth as a Graph

Project Overview

The interactive prototype offers insights into the behavior of the Earth as a Graph model, which is currently under development. This model explores spatial interconnections within weather data using ERA5 datasets provided by ECMWF. By visualizing both the model’s predictions and how data points are grouped throughout the training process (based on training epochs), the prototype provides a window into the model’s learning dynamics. It reflects the current state of the model and helps illustrate how spatial relationships in climate data are captured and learned over time. As this is part of an ongoing research project, we are not disclosing further technical details at this stage. The prototype will be expanded in the future, following the release of the final model, and will include comprehensive visualizations and a detailed description of the model architecture and setup.

Dashboard Features

The main dashboard provides an intuitive interface for selecting various parameters related to the choice of model. Users can select from four different datetimes (Date1-4), three variables (Temperature, Precipitation, WindSpeed), various lead times (6, 12, 18 hours), and multiple training epochs (10, 20, 40, 60, 80, 100, 150, 200).

Visualization Components

The platform features a dual-panel prediction visualizer that displays model predictions alongside ground truth data for direct comparison. The system dynamically loads epoch-specific visualization images, allowing users to analyze how model performance varies with different training configurations. Additionally, an attention-based spatial grouping panel provides insights into how the model focuses on different geographical regions during prediction.

Interactive Analysis

Through the parameter selection interface, researchers can explore how environmental predictions change for different datetimes, variables and model training iterations. This enables comprehensive analysis of model behavior, prediction accuracy, and spatial-temporal patterns in Earth system dynamics.
