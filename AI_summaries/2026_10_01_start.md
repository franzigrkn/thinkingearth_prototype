# Earth-2 Interactive Visualization Plan

## Goal

Provide a public, browser-accessible visualization of precomputed model predictions using NVIDIA Earth-2 Command Center (E2CC). E2CC will run on a GPU server and stream to reviewers through WebRTC; no model inference is required.

## Development environment

- Begin on a company GPU workstation; a cloud GPU is not needed for development.
- Preferred setup: Ubuntu 22.04, RTX GPU with 48 GB VRAM, 32 CPU cores, 64 GB RAM, and at least 128 GB NVMe storage.
- Install Git LFS, Docker, NVIDIA Container Toolkit, Python 3.12, and `uv`.
- Keep the existing Flask prototype and NVIDIA Earth-2 Weather Analytics/E2CC codebases separate initially.

## First implementation

1. Build and run the unmodified E2CC reference application locally.
2. Convert one raw 0.25° global temperature prediction into an unannotated equirectangular texture. Do not reuse the existing projected plot images.
3. Create E2CC metadata for the texture and verify that it maps correctly onto the globe.
4. Add selected 2018 timestamps and use the E2CC timeline for selection/playback.
5. Add the remaining variables and prediction, ground-truth, and error layers with consistent units and color ranges.
6. Enable WebRTC and test browser access locally and from another machine on the company network.

## Public deployment

- After local validation, package the E2CC viewer for deployment on a public GPU host or an approved company-hosted GPU server.
- Add HTTPS, authentication, and WebRTC/TURN networking as required.
- Link or embed the stream from the existing Flask website.
- Plan for one GPU-backed session per independent concurrent reviewer; start with a single-session deployment.

## Initial scope exclusions

- No live model inference
- No Data Federation Mesh or Earth2Studio runtime
- No scalable multi-user infrastructure until the single-session viewer is validated
